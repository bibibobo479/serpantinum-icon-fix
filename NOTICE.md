# Attribution

Serpantinum Icon Fix is an independent repair utility for
[ilyamiro/serpantinum](https://github.com/ilyamiro/serpantinum), maintained by
Illia Miroshnichenko and contributors and distributed under AGPL-3.0.

The QML match/replacement patterns and compact regression fixtures are adapted
from Serpantinum's launcher and dock code (tested installation: version 2.3.0,
commit a62f825). Those authors retain their copyrights. This project is distributed
under AGPL-3.0-only; see LICENSE.

The hicolor index is generated locally from standard directory conventions and
installed directories. No theme artwork or upstream hicolor index is bundled.

Technical references:

- [Freedesktop Icon Theme Specification](https://specifications.freedesktop.org/icon-theme/latest/)
- [Quickshell iconPath documentation](https://quickshell.org/docs/v0.2.1/types/Quickshell/Quickshell/)

Serpantinum and installed theme names are used only to identify compatible software.
